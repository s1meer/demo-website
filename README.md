## 🌐 How to Access the Website

### Method 1: Using the Python Server (Recommended)

1. Navigate to the website directory:
   ```bash
   cd /mnt/user-data/outputs/saccos_complete_site
   ```

2. Run the server:
   ```bash
   python3 start_server.py
   ```

3. Access the website at:
   - **Local**: http://localhost:8000
   - **Network**: http://YOUR_IP_ADDRESS:8000

4. Share the network URL with anyone on the same network!

### Method 2: Direct File Access

Simply open `index.html` in any web browser.
